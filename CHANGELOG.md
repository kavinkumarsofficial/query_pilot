# Changelog

## 1.0.1

- Improved package description in pubspec.yaml for pub.dev conventions.
- Added comprehensive dartdoc comments across all public APIs.
- Cleaned up package exports and removed unnecessary demo file from `lib/`.

## 1.0.0+1

- Initial release of QueryPilot.
- Added typed query caching, stale-time handling, focus/resume refetching, and cache invalidation.
- Added typed mutations with optimistic updates and rollback support.
- Added `QueryBuilder`, `QueryPilotScope`, and a runnable demo app.
